# Центр размещения — сайт-визитка хостела (Владимир)

Одностраничный сайт-визитка с калькулятором цен, тремя языками (русский / английский / узбекский),
светлой и тёмной темой, отправкой заявок в Google Таблицы. Полностью адаптивный.

## Структура проекта

```
├── index.html          # сама страница
├── css/styles.css      # стили (адаптив + темы)
├── js/
│   ├── config.js       # настройки: URL Google Таблиц, контакты
│   ├── i18n.js         # переводы (ru / en / uz)
│   ├── main.js         # язык, тема, меню, модалки
│   ├── calculator.js   # калькулятор (пока скрыт блюром)
│   └── form.js         # отправка заявок в Google Таблицы
├── google-sheets/
│   └── Code.gs         # код для Google Apps Script
├── images/             # сюда позже добавите свои фото
├── .gitignore
└── vercel.json         # настройки хостинга Vercel
```

## 1. Настройка Google Таблиц (приём заявок)

Форма на сайте отправляет заявку (имя, телефон, тип клиента, комментарий) в вашу Google Таблицу.

1. Откройте [Google Таблицы](https://sheets.google.com) и создайте новую таблицу (например, «Заявки хостела»).
2. В меню выберите **Расширения → Apps Script**.
3. Удалите содержимое редактора и вставьте весь код из файла **`google-sheets/Code.gs`**.
4. Нажмите **Развернуть → Новое развертывание** → рядом с «Веб-приложение» — значок шестерёнки.
5. Настройки развертывания:
   - **Выполнение от имени**: «Я»
   - **Доступ**: «Все, у кого есть ссылка»
6. Нажмите **Развернуть**, подтвердите доступ (разрешите приложению работать с таблицей).
7. Скопируйте **URL веб-приложения** (выглядит примерно так: `https://script.google.com/macros/s/AKfycb.../exec`).
8. Откройте **`js/config.js`** и вставьте этот URL в поле:

```js
sheetsUrl: "https://script.google.com/macros/s/AKfycb.../exec",
```

Готово — заявки с сайта начнут падать в лист «Заявки» таблицы.

> Как проверить без сайта: в редакторе Apps Script запустите функцию `testPost()` — в таблице появится тестовая строка.

## 3. Публикация на Vercel (бесплатный хостинг)

1. Зайдите на [vercel.com](https://vercel.com) и войдите через GitHub.
2. Нажмите **Add New → Project** → выберите репозиторий `hostel-site`.
3. Vercel сам определит проект (это статический сайт). Нажимайте **Deploy**.
4. После деплоя у вас будет адрес вида `https://hostel-site.vercel.app`.

### Подключение своего домена

1. В панели проекта: **Settings → Domains**.
2. Добавьте ваш домен (например, `vash-hostel.ru`).
3. Vercel покажет DNS-записи (обычно A-запись `76.76.21.21` или CNAME `cname.vercel-dns.com`) — добавьте их у вашего регистратора домена.
4. Включите HTTPS (Vercel выпустит бесплатный сертификат автоматически).

## 4. Как включить калькулятор позже (когда узнаете цены)

1. В **`js/calculator.js`** заполните объект `RATES` реальными тарифами:

```js
var RATES = {
  bunk:    { individual: 500,  organization: 450 },   // койко-место за сутки
  private: { individual: 1500, organization: 1300 }   // отдельная комната за сутки
};
```

2. В **`index.html`** снимите блюр: добавьте атрибут `style="display:none"` блоку `.calc__blur` и уберите `aria-hidden="true"` у блока `.calc__panel`.
3. При необходимости добавьте новые типы размещения в `<select id="calcRoom">` и их переводы в `js/i18n.js`.

## 5. Замена контактов и фото

- **Контакты** — правьте `js/config.js` (телефон, email) и тексты в `index.html`.
- **Галерея** — положите свои фото в папку `images/` и замените `src` у картинок в секции галереи.
- **Данные хостела** (адрес и т.п.) — в файлах `index.html` и `js/i18n.js` (ключи `heroAddress`, `contactAddrValue`).
